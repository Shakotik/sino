# Как читать код Sino

## React-компонент

Компонент — это функция, которая описывает часть интерфейса. Например, `StudyHome` описывает страницу «Учёба».

## JSX

JSX похож на HTML, но находится внутри JavaScript. Поэтому в нём можно выводить данные в фигурных скобках: `{level.name}`.

## State

`useState` хранит значение, которое меняется во время работы страницы. В первой версии это выбранный HSK-уровень. Когда состояние изменяется, React сам перерисовывает нужную часть интерфейса.

## Данные отдельно от интерфейса

`src/data/studyDemo.js` не рисует страницу. Он только хранит данные. Это правило поможет позже заменить демонстрационные данные на настоящую базу без переписывания дизайна.

## Правило следующего шага

Меняем одну маленькую вещь → сохраняем → смотрим результат → понимаем, почему это сработало. Не вставляем большой чужой код, пока не можем объяснить его роль.
