# Русские каталоги HSK 2–6

Карточки HSK 2–6 собраны из предоставленных русскоязычных PDF. Каждая
карточка содержит иероглифы, пиньинь с тонами и русское значение — поэтому в
тренажёре больше не показывается временный английский перевод.

| Уровень | Карточек в PDF | Файл интерфейса |
| --- | ---: | --- |
| HSK 2 | 200 | `src/data/hsk2Vocabulary.js` |
| HSK 3 | 973 | `src/data/hsk3Vocabulary.js` |
| HSK 4 | 1 000 | `src/data/hsk4Vocabulary.js` |
| HSK 5 | 1 071 | `src/data/hsk5Vocabulary.js` |
| HSK 6 | 1 140 | `src/data/hsk6Vocabulary.js` |

Это количество строк именно в предоставленных документах. HSK 1 пока остаётся
отдельным существующим каталогом из 300 слов и не менялся этой загрузкой.

## Откуда берутся данные

Исходный, проверяемый результат извлечения лежит в
`data/sources/russian-hsk2-6-from-pdfs.json`. Он не загружается браузером:
скрипт сборки преобразует его в отдельные JavaScript-файлы, и сайт загружает
только каталог открытого пользователем уровня.

| Уровни | Предоставленный файл | Указанный в документе источник |
| --- | --- | --- |
| HSK 2 | `HSK2_3.0_список_словаря_русский_2026.pdf` | Chinesimple by Khanji School |
| HSK 3 | `HSK_3_0_Uroven_3.pdf` | vk.com/oskolchinese |
| HSK 4 | `HSK_3_0_Uroven_4.pdf` | vk.com/oskolchinese |
| HSK 5 | `HSK_3_0_Uroven_5.pdf` | vk.com/oskolchinese |
| HSK 6 | `HSK_3_0_Uroven_6.pdf` | vk.com/oskolchinese |

Скрипт `scripts/extractRussianHskPdfCatalogs.py` читает не просто текст
страниц, а колонки таблиц. Для HSK 2 это особенно важно: из-за высокой строки
перевод на странице может находиться визуально выше номера слова. Скрипт также
приводит специальные символы радикалов к обычным иероглифам, например `⻔口`
к `门口`.

## Важная проверка прав

Файлы были предоставлены для этого проекта, но это **не означает автоматически
разрешение на публичное или коммерческое распространение их словарных
переводов**. В HSK 2 прямо указано «Copyright Chinesimple by Khanji School»;
в материалах HSK 3–6 указан авторский канал. До запуска сайта в общий доступ
нужно получить письменное разрешение или заменить переводы собственными,
отредактированными преподавателем. Код и дизайн Sino от этого не зависят.

## Как обновить каталог

Если один из PDF будет заменён, положите файл с тем же именем в папку
`C:\Users\Legion\Downloads`, затем из папки `hazii` выполните:

```powershell
npm run data:extract:russian-hsk2-6
npm run data:build:hsk2-6
npm run db:seed:hsk2-6
```

Первая команда требует установленный Python с библиотекой `pdfplumber`.
Вторая обновляет файлы, которые использует сайт. Третья добавляет те же русские
карточки в локальный PostgreSQL Docker; она безопасно обновляет слова по их
номеру в списке и убирает прежние временные английские значения HSK 2–6.
