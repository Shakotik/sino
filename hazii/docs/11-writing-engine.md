# Движок прописей

## Что происходит во время тренировки

1. Пользователь открывает «Карточки» → HSK → «Прописи». Отдельного пункта
   бокового меню больше нет. Адрес занятия: `/study/:levelId/writing`.
2. В плавном модальном окне выбираются режим, группа слов, количество слов
   (1–100), порядок и длина серии иероглифов (1–10, для обучения).
3. В обучении каждый знак серии сначала обводится по контуру. Доступна
   кнопка показа полного порядка черт. Затем та же серия повторяется по памяти.
   При длине 1 получается непосредственный цикл «трафарет → пустое поле».
4. В проверке сразу показывается пустое поле. Пиньинь, перевод и номер знака
   помогают понять задание; китайские примеры из текста перевода маскируются.
5. Hanzi Writer проверяет форму, направление и порядок каждой черты.
   После завершения пользователь сам нажимает кнопку следующего шага.
6. Старое поле полностью размонтируется, следующее начинается заново.
   Знаки составного слова сохраняют порядок слева направо. Повторяющиеся
   знаки — самостоятельные позиции, а не один уникальный иероглиф.
7. Если данные не загрузились, доступен повтор загрузки; в проверке можно
   пропустить знак без зачёта. Обычная обводка больше не пропускается.
   В конце показываются результаты и кнопка повторения сложных слов.

Пример серии длиной 3: для слов 爸爸 и 爱 задания идут как
«爸 по трафарету, 爸 по трафарету, 爱 по трафарету», затем эти же три
позиции по памяти. Последняя серия занятия может быть короче указанной.

Прогресс сохраняется только после самостоятельного написания всех знаков
слова без ошибок в успешных попытках. Ошибки первой попытки сохраняются,
даже если новая попытка успешна. Кнопка очистки поля не обнуляет ошибки.
Запрос трафарета в проверке помечает первую попытку как несамостоятельную;
обводка сама по себе не даёт зачёт и обязательно заканчивается повтором без
образца. Уже изученные слова не становятся неизученными из-за новой ошибки.

Старые `/writing/:levelId` перенаправляются в настройки курса; `/writing`
ведёт к выбору HSK. Ссылки обучения/проверки с `mode=writing` тоже используют
единый новый тренажёр. Старые компоненты отдельного раздела больше не
подключены к маршрутам. Движок не является SDK Skritter — используется
открытый Hanzi Writer с аналогичным принципом упражнений.

## Модули

| Файл | Ответственность |
| --- | --- |
| `HanziQuiz.jsx` | Проверка черт; `guided=true` показывает контур, по умолчанию ответ скрыт. |
| `strokeDemonstration.js` | Полная анимация порядка черт и возврат к практике без зачёта. |
| `writingPractice.js` | Чистые функции: позиции знаков, очередь серий, оценка попыток и целого слова. |
| `WritingCharacterStep.jsx` | Один знак, смена трафарета/памяти, ошибки, повтор, пропуск и состояние загрузки. |
| `CourseWritingSession.jsx` | Каталог HSK, настройки, сеанс, результаты и сохранение прогресса. |
| `CourseSettingsForm.jsx` | Общие настройки курса и параметры прописей. |
| `studyStorage.js` | Настройки и подтверждённый прогресс локального профиля. |

## Данные на собственном сервере

С 9 октября 2026 подключён собственный `charDataLoader`: данные пакета
hanzi-writer-data 2.0.1 выдаются через `/api/hanzi/:character`. Внешний CDN
больше не требуется. Все 1 771 уникальные китайские знаки текущих HSK 1–6
найдены в этом пакете; браузер запрашивает только текущий знак. Для работы
нужно запустить API. При публикации нужно перенести и API, и зависимость с
данными на выбранный сервер, сохранив условия Arphic Public License.
Текст лицензии доступен на `/api/hanzi-license`.

Это клиентская проверка: ответ скрыт визуально, но технически данные знака
доступны браузеру. Для защищённого экзамена требуется отдельная серверная
модель проверки. Данная версия предназначена для самостоятельной учёбы.
