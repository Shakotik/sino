# Docker в Sino: локальная среда разработки

## Что такое Docker

Docker запускает программы в **контейнерах**. Контейнер — это изолированная
маленькая среда с уже установленной программой и её настройками.

Вместо ручной установки PostgreSQL и Redis в Windows мы даём Docker инструкцию:

```text
«Скачай PostgreSQL 16, создай для него отдельное место хранения
и открой доступ только с этого компьютера».
```

Это решает три практические задачи:

1. У каждого разработчика одинаковая версия базы данных.
2. Удаление контейнера не удаляет Windows и другие программы.
3. Проект легко запустить на новом компьютере одной командой.

### Новые термины

| Термин | Простое объяснение |
|---|---|
| Docker image | шаблон программы, например готовый PostgreSQL |
| Container | запущенный экземпляр этого шаблона |
| Volume | отдельное хранилище, сохраняющее данные базы после остановки контейнера |
| Docker Compose | файл, который запускает несколько связанных контейнеров одной командой |
| Port | номер «двери» программы на компьютере; PostgreSQL Sino использует `5433` |

## Что запускает Sino сейчас

`docker-compose.yml` поднимает два локальных контейнера:

| Контейнер | Для чего нужен | Адрес с вашего компьютера |
|---|---|---|
| PostgreSQL 16 | будущие пользователи, слова, прогресс, подписки | `localhost:5433` |
| Redis 7 | кеш, ограничения частоты, фоновые задачи | `localhost:6380` |

Они специально привязаны к `127.0.0.1`, поэтому не доступны из интернета.
Сайт React пока не подключается к ним: сначала появится серверный API.

## Файлы

```text
docker-compose.yml                 # инструкция Docker Compose
.env                               # локальные настройки; Git его игнорирует
.env.example                       # безопасный образец настроек
infra/postgres/init/01-create-schemas.sql
                                  # создаёт логические схемы БД при первом запуске
```

## Основные команды

Все команды выполняются в терминале VS Code, когда открыта папка `hazii`.

```powershell
# Запустить контейнеры в фоне
docker compose up -d

# Увидеть состояние контейнеров
docker compose ps

# Посмотреть сообщения PostgreSQL
docker compose logs postgres

# Остановить контейнеры, сохранив данные
docker compose stop

# Снова запустить остановленные контейнеры
docker compose start
```

Команда `docker compose down` удаляет контейнеры и сеть, но сохраняет volumes
с данными. Команду с `--volumes` пока не используйте: она удаляет локальную
базу и данные Redis.

## Подключение к PostgreSQL позже

Когда появится backend, его строка подключения будет выглядеть так:

```text
postgresql://hazii_app:change-me-local-only@localhost:5433/hazii_dev
```

Это только локальный учебный пароль. Он не подходит для production и не должен
быть помещён в публичный репозиторий.

## Если Docker не запускается

1. Откройте Docker Desktop и дождитесь статуса **Engine running**.
2. В терминале выполните `docker info`.
3. Если команда показала информацию о сервере, повторите `docker compose up -d`.
4. Если ошибка остаётся, пришлите полный текст ошибки, не добавляя пароли.
