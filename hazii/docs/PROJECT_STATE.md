## Прописи внутри курсов — 9 октября 2026

- Убрана отдельная вкладка «Прописи» из бокового меню. В каждом HSK 1–6
  появилась плитка «Прописи»; маршрут `/study/:levelId/writing`.
- Перед запуском выбираются режим, группа слов, 1–100 слов за занятие,
  порядок и 1–10 иероглифов в серии. По умолчанию серия из одного знака:
  обводка по трафарету → чистое поле для повторения по памяти.
- При серии из нескольких знаков сначала обводится вся серия, затем те же
  знаки повторяются по памяти в том же порядке. Последняя серия может быть
  короче; серия может пересекать границу слов. Внутри слова порядок сохраняется.
- Есть отдельная проверка сразу по памяти. При запросе трафарета в этом
  режиме первая попытка не считается самостоятельной, а после обводки всё
  равно требуется новая попытка без образца.
- Каждый знак многознакового слова — отдельное задание, включая повторы вроде
  爸爸. Целое слово засчитывается только после правильного самостоятельного
  написания всех его позиций. Обводка, пропуск и отсутствие данных не дают зачёт.
- Очистка поля не стирает ошибки текущей попытки; новая успешная попытка
  учитывается как закрепление, но не исправляет статистику первого ответа.
- Переходы между шагами происходят по кнопке, без таймера. При смене фазы
  старый экземпляр поля уничтожается, образец не остаётся на новом поле.
  Китайские примеры в тексте перевода также скрыты, чтобы не выдавать ответ.
- Ссылки старого отдельного раздела и старых учебных режимов ведут в единый
  тренажёр. Прежний внешний вид обычных карточек не менялся.
- Проверены линтер, production-сборка и 23 теста, включая PostgreSQL,
  очереди серий, повторные знаки, пропуски, повторные попытки, разметку
  настроек/курсов и доступность данных черт для всех HSK 1–6. Через сайт
  проверены ответ 200 новой страницы и загрузка восьми черт 爸 из API.
- Проверка разметки — SSR, а не визуальный браузерный тест. Проверить новый
  цикл реальным рисованием и мобильные размеры в этой итерации не удалось:
  инструмент управления браузером завершился с ошибкой среды Windows
  `setup refresh had errors`. Эти проверки остаются открытыми.

Устройство: [Движок прописей](11-writing-engine.md).

## Обновление раздела карточек — 9 октября 2026

- Кнопки курса открывают рабочие разделы: обучение, проверку знаний, ANKI,
  список слов, настройки и собственные карточки. Убраны время в курсе,
  «Инструкции» и «Об упражнении».
- Перед упражнением открываются настройки. Для обычных карточек выбирается
  группа: изученные, неизученные или все слова; основной экран сохранён.
- Обучение и проверка поддерживают русский перевод, китайский клавиатурный
  ввод и рукописный порядок черт. Правильный ответ сразу сохраняет прогресс;
  результат первой попытки учитывается отдельно от успешной пересдачи.
- Шкала 0–100 использует словарные значения, небольшой проверяемый набор
  синонимов и подсказку об опечатке. Это локальная эвристика, а не нейросетевая
  семантическая модель. Неизвестные правильные синонимы могут отклоняться.
- Прописи работают на Hanzi Writer. Данные hanzi-writer-data 2.0.1 обслуживает
  собственный API `/api/hanzi/:character`; покрыты все 1 771 уникальные китайские
  знаки текущих каталогов. Подключения к закрытому SDK Skritter нет.
- ANKI — собственный режим интервального повторения, без AnkiWeb. Есть
  очередь по срокам, лимит новых слов в день и оценки сложности. Напоминания
  работают внутри открытого Sino и, с разрешения, через системные уведомления.
  Для закрытого сайта доступен экспорт ежедневного события календаря в 18:00;
  его нужно импортировать. Серверные фоновые Web Push ещё не реализованы.
- Личные карточки хранятся в схеме `personal`: владелец, карточки, прогресс,
  подтверждения попыток для защиты от двойного учёта при повторе запроса.
  В профиле есть отдельные шкалы и окно статистики по своим словам.
- Сервер проверяет случайный секрет коллекции и хранит только его хеш.
  Переданного браузером ID пользователя недостаточно для доступа к карточкам.
  Это временная модель: локальные профили можно переключать без пароля на том
  же устройстве; очистка данных браузера удаляет ключ доступа. Полноценного
  входа, восстановления и синхронизации между устройствами пока нет.
- Прогресс HSK, история дней, настройки и ANKI разделены по локальным профилям.
  Выход сохраняет профиль для повторного выбора. Данные старого формата
  мигрируют только к одному владельцу.
- Панда выровнена с текстом. Её окно получило скруглённый стеклянный дизайн
  и одинаковое плавное появление/исчезновение.
- Схема применена к локальному PostgreSQL. Проверены изоляция коллекций,
  повторная отправка оценки, сохранение карточки и результата после перезагрузки,
  синоним «нравится», ввод 爱 и распознавание обеих черт 八 в браузере.

Подробности: [Учебные режимы и личные карточки](12-study-and-personal-cards.md).

## Цель продукта

Sino — веб-приложение для изучения китайских слов и тренировки написания
иероглифов. Целевой масштаб первой полной версии — 30–40 тысяч
зарегистрированных пользователей. Бесплатный HSK 1 доступен всем; премиум
функции открываются по активному праву доступа (подписке или выданному
администратором доступу).

  результат в браузере через `localStorage`.

- Прописи доступны внутри каждого HSK 1–6: трафарет, затем повтор по памяти,

- Прописи проверяют черты на Hanzi Writer. При недоступности данных интерфейс

- Добавлены локальная схема каталога PostgreSQL и повторяемый загрузчик 300

## Зафиксированные решения

| Область | Решение | Статус |
|---|---|---|
| Фронтенд | React; текущий учебный код — JavaScript, рабочие сервисы — TypeScript | принято |
| Архитектура | Контракты логических микросервисов; развёртывание поэтапное, без лишнего дробления на старте | принято |
| Главная БД | PostgreSQL с отдельными схемами и ролями сервисов | принято |
| Кеш и короткоживущие данные | Redis | принято |
| Асинхронные события | NATS JetStream | принято |
| Файлы и траектории письма | S3-совместимое объектное хранилище | принято |
| Платёжный принцип | Доступ открывает только подтверждённое сервером событие оплаты | принято |
| Авторизация | Google OpenID Connect и Яндекс ID OAuth 2.0; локальный пароль не входит в первый релиз | принято |
| Учебный тест письма | Целевой иероглиф не отправляется в браузер до проверки; в слове иероглифы идут последовательно | принято |

## Плановые допущения нагрузки

Число зарегистрированных пользователей не равно числу одновременных посетителей.
До измерений приняты консервативные ориентиры: 40 000 зарегистрированных,
5 000 дневных активных, до 500 одновременных сессий и до 50 запросов в секунду
на чтение в пике. Перед открытием платного доступа эти цифры нужно заменить
результатами нагрузочного теста.

## Открытые решения

- До публичного или платного запуска получить разрешение на повторное
  использование переводов из PDF Chinesimple by Khanji School и
  vk.com/oskolchinese либо заменить их собственными, отредактированными
  преподавателем переводами.
- Выбрать российского облачного провайдера, домен, почтового провайдера и
  платёжного провайдера после регистрации юридического лица/ИП.
- Утвердить тарифы: помесячная, годовая подписка и/или покупка уровней.
- Настроить и проверить с преподавателем допустимую строгость проверки черт;
  текущий движок проверяет форму, направление и последовательность.
- Убрать данные целевого иероглифа из браузера во время проверки: текущий MVP
  скрывает его визуально, но каталог для карточек загружается на клиент. Для
  строгого режима нужен серверный одноразовый сеанс письма и сервис распознавания.

## Ближайшие действия

1. Проверить выборочно русские переводы HSK 2–6 с преподавателем и подтвердить
   права на их публичное использование.
2. Создать API, которое будет читать каталоги из PostgreSQL вместо локальных
   JavaScript-файлов.
3. Подключить к прописям серверную проверку черт и одноразовые задания.
4. Перенести сохранение прогресса из браузера в аккаунт пользователя.
5. Добавить полноценный вход и восстановление доступа к личным коллекциям.
6. Расширить проверенные русские синонимы; отдельно оценить качество
   семантической модели, прежде чем использовать её для автоматического зачёта.
7. После HTTPS-развёртывания подключить серверные Push-напоминания и проверить
   мобильные устройства. Локальные уведомления не будят закрытый браузер.
