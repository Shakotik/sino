# Каталог слов HSK 1

## Что есть в MVP

Файл `src/data/hsk1Vocabulary.js` — временный локальный каталог для
фронтенда. В нём 300 записей из предоставленного файла
`cli-hsk-1-vocabulary.csv`, помеченного как `HSK 3.0 Level 1`.

Каждая запись содержит:

- `id` — номер слова из исходной таблицы;
- `hanzi` — написание на китайском;
- `pinyin` — чтение с тонами;
- `translationRu` — короткий русский учебный перевод;
- `translationEn` и `partOfSpeech` — исходные справочные поля из таблицы.

Модуль нужен карточкам прямо сейчас, не открывая браузеру доступ к PostgreSQL.
Для локальной базы также добавлены схема `02-catalog-schema.sql` и загрузчик
`scripts/seedHsk1Postgres.mjs`: они создают `catalog.hsk_levels`,
`catalog.lexemes` и `catalog.lexeme_senses`, а затем загружают те же 300 слов.

После старта Docker команды выполняются из папки `hazii`:

```powershell
npm run db:migrate:catalog
npm run db:seed:hsk1
```

Их можно запускать повторно: слова обновляются по номеру из исходной таблицы,
а не создаются второй раз. В будущем интерфейс перестанет читать этот локальный
файл напрямую и будет получать каталог через API.

## Как понимать число 300

На референсном изображении указано `500`, но в полученном CSV — ровно 300
строк. Поэтому MVP честно показывает 300 как общее число слов. В будущем нужно
зафиксировать одну версию списка HSK для каждого курса: HSK 2.0, стандарт 2021
года и новый список HSK — это разные перечни с разным количеством слов.

## Лицензии перед публикацией

CSV был передан для работы над проектом, но его происхождение и лицензия не
указаны в самом файле. До коммерческого запуска нужно подтвердить право на его
повторное использование и записать источник в `catalog.content_sources`.

Русские переводы в текущем MVP — короткие учебные глоссы; их необходимо
вычитать преподавателю китайского. Для пополнения и проверки каталога годятся
только источники с явно указанной лицензией. Например, Kaikki/Wiktionary
публикует машиночитаемые словарные данные на условиях CC BY-SA и GFDL, а
CC-CEDICT — на условиях CC BY-SA. Для этих источников потребуется указание
авторов и соблюдение условий ShareAlike. Не следует переносить данные из
словаря или GitHub-репозитория, если в нём нет явной лицензии.
