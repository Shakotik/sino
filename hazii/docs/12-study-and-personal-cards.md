# Учебные режимы и личные карточки

Актуально на 9 октября 2026. Это описание реализованной локальной версии,
а не обещание готовности к публичной нагрузке или приёму оплаты.

## Пользовательский путь

Курс HSK открывает меню. «Карточки слов» предлагает изученные, неизученные
или все слова и сохраняет прежний интерфейс переворачивающихся карточек.
Фильтр фиксируется на проход, чтобы после оценки карточки очередь не перескакивала.
Пустые наборы и ошибки загрузки имеют отдельные состояния.

Перед обучением и проверкой выбираются способ, группа слов, количество 1–100
и порядок. Обучение сначала знакомит со словом; проверка сразу задаёт вопрос.
Ввод и проверка прописей не показывают целевой ответ заранее. В режиме русского перевода
иероглиф показан намеренно: это вопрос упражнения. Клавиатурный ввод учитывает
китайский IME: Enter при выборе знака не отправляет незавершённый ответ.

После занятия есть результаты и повтор сложных слов. Первая попытка и
последующее закрепление различаются. Корректный ответ сохраняется сразу,
даже если человек не нажал «Следующее слово».

## Оценка русского перевода

`answerEvaluation.js` нормализует регистр, ё/е, пробелы и пунктуацию,
разбирает словарные варианты и сравнивает их с ответом:

| Результат | Балл | Автоматический зачёт |
|---|---:|---|
| Одно из словарных значений | 100 | Да |
| Синоним из проверяемой группы | 95 | Да |
| Похожее написание, возможная опечатка | Не выше 74 | Нет |
| Не найдено совпадение | 0 | Нет |

«Любить» и «нравиться» принимаются как значения 爱. Отрицание, случайная
подстрока или набор несвязанных слов не дают зачёт. Шкала приблизительна:
сходство букв не является семантическим расстоянием. Модель эмбеддингов/LLM
не подключена; необычные верные перефразы могут не распознаться. Словарный
ответ показывается после ошибки для осмысленной повторной попытки.

## Прописи

«Прописи» перенесены из бокового меню в каждый курс HSK. Перед занятием
задаются 1–100 слов и, в обучении, серия из 1–10 иероглифов. Сначала серия
обводится по трафарету, затем повторяется на пустых полях в том же порядке.
Режим проверки начинает сразу по памяти. Подробнее: [Движок прописей](11-writing-engine.md).

`HanziQuiz.jsx` использует Hanzi Writer 3.5.0. Во время обводки доступны контур
и следующая черта. Проверка скрывает контур. По просьбе ученика можно снова
обвести трафарет, но это считается помощью и затем требует новой попытки
по памяти. Для многознакового слова каждый знак пишется отдельно. Ошибка не
стирается очисткой холста; успешный повтор учитывается отдельно от первого
ответа. Только самостоятельное написание всех знаков даёт зачёт слова.
При ошибке загрузки зачёта нет.

Данные hanzi-writer-data 2.0.1 установлены на сервере; запрос одного знака
идёт на `/api/hanzi/:character`. Браузер не скачивает всю базу и не обращается
к внешнему CDN. В текущих HSK 1–6 все 1 771 уникальные китайские знаки имеют
данные. Пакет требует около 32 МБ на сервере. Движок и данные имеют разные
лицензии: для данных сохраняется Arphic Public License. Её текст доступен
по `/api/hanzi-license` и в установленном пакете. Это аналогичный Skritter
сценарий занятий, а не интеграция с продуктом Skritter.

## ANKI и напоминания

`ankiScheduler.js` — чистые функции расчёта; `ankiStorage.js` — хранение
очереди профиля. Сначала выдаются подошедшие повторения, затем новые слова
в пределах дневного лимита. «Снова» возвращает слово через минуту,
«Трудно» для нового слова — через 6 минут, «Хорошо» — через день,
«Легко» — через 4 дня. Следующие удачные повторения увеличивают интервал.
Приложение не синхронизируется с AnkiWeb и не заявляет использование FSRS.

`AnkiReminders.jsx` проверяет сроки при открытии, возврате фокуса и раз в минуту.
Системные уведомления запрашиваются только кнопкой пользователя, ограничены
одним напоминанием за курс в день. Внутреннее напоминание можно отложить на час.
`reminders-sw.js` показывает уведомление и обрабатывает переход в нужный курс;
он не работает как будильник закрытого приложения.

Экспорт `.ics` создаёт ежедневное событие с завтрашнего дня в 18:00 по местному
времени календаря. После скачивания требуется импорт. Оно напоминает о занятии
ежедневно, а не получает динамическую очередь ANKI. Настоящие фоновые Push
потребуют публичного HTTPS, подписок устройств и серверного планировщика.

## Хранение и владение

| Данные | Где находятся |
|---|---|
| Каталоги HSK | Подгружаемые по уровню файлы `src/data` |
| Прогресс HSK, календарь, настройки, ANKI | localStorage с префиксом ID локального профиля |
| Полный БКРС | Отдельная схема PostgreSQL `dictionary` |
| Собственные карточки и результаты | PostgreSQL `personal` |
| Ключ личной коллекции | Браузер; сервер хранит только SHA-256 хеш |

Таблицы `personal.accounts`, `personal.cards`, `personal.card_progress`,
`personal.review_receipts` создаёт повторяемая миграция `04-personal-cards.sql`.
Собственные карточки не изменяют публичные каталоги HSK или словарь БКРС.
Каждый запрос CRUD, статистики и оценки ограничен владельцем, определённым
по случайному секрету. Чужой ID карточки не даёт доступа. SQL параметризован,
размеры входных полей ограничены, ответ приватный и не кешируется.

Один и тот же запрос оценки с одинаковым requestId учитывается один раз.
Уникальность `(owner_id, hanzi)` защищает от дублирования карточек. Лимит
локальной версии — 2 000 карточек на коллекцию. Для публичной версии нужны
настоящая авторизация, восстановление, пагинация больших наборов и измерения нагрузки.

Выход из профиля сохраняет его в списке «Продолжить на этом устройстве».
Это не защищённый вход: любой пользователь этого браузера может выбрать
сохранённый профиль. Очистка браузера удаляет ключ коллекции; восстановление
доступа по email/OAuth пока отсутствует. Нельзя выдавать эту модель за
полноценные защищённые аккаунты для публичного сервиса.

## Основные модули

- `HskCourseHub.jsx`, `CourseSettingsForm.jsx`, `StudyDialog.jsx` — выбор занятия.
- `StudySession.jsx`, `answerEvaluation.js` — упражнения и оценка.
- `CourseWordList.jsx` — поиск и отметки изученности в каталоге.
- `AnkiSession.jsx`, `ankiScheduler.js` — очередь повторений.
- `profileStorage.js`, `localProfile.js`, `studyStorage.js` — локальное владение прогрессом.
- `features/personal/` — редактор, личная практика и статистика в профиле.
- `api/personalCards.mjs` — проверка владельца, запросы БД и интервалы личных карточек.

## Проверки

`npm run lint`, `npm test`, `npm run build` — обычные проверки.
Тесты с настоящим PostgreSQL запускаются после миграции:

```powershell
$env:PERSONAL_CARDS_DB_TESTS = '1'
npm test
Remove-Item Env:PERSONAL_CARDS_DB_TESTS
```

Тест создаёт только свои временные коллекции и удаляет только их. Проверяет
отказ чужому владельцу, сохранение/изменение/удаление карточек, статистику и
безопасный повтор оценки после потери ответа. Пользовательские записи не очищаются.
Отдельные тесты проверяют синонимы, отрицания, порядок введённых знаков,
интервалы, дневной лимит и сохранение локальной идентичности при выходе.
