# Sino — учебный проект

Sino — веб-приложение для изучения китайского языка. Работают карточки HSK 1–6,
обучение и проверка знаний, прописи с распознаванием черт, интервальное повторение,
словарь БКРС и собственные карточки с отдельной статистикой. Интерфейс — React/Vite,
сервер — Node.js/Express, данные — PostgreSQL, кеш словаря — Redis.

Профили пока локальные: полноценный вход по паролю/OAuth и восстановление доступа
ещё не подключены. Личные карточки находятся в БД, их ключ доступа — в браузере.
Прогресс HSK и очередь ANKI сохраняются отдельно для каждого локального профиля.

## Открыть проект

1. В VS Code выберите **File → Open Folder…**.
2. Откройте папку `hazii`.
3. Откройте **Терминал → Создать терминал**.
4. Выполните:

   ```powershell
   npm run dev -- --host 127.0.0.1 --port 4173
   ```

5. Откройте `http://127.0.0.1:4173/`. Для работы всех разделов нужен также API ниже.

## Запустить сайт полностью

Сначала откройте Docker Desktop. В терминале папки `hazii` запустите базу:

```powershell
docker compose up -d
```

При первом запуске после получения обновлений установите зависимости и примените
миграцию личных карточек (повторный запуск миграции не удаляет данные):

```powershell
npm install
npm run db:migrate:personal
npm run db:migrate:folders
```

В этом же терминале запустите API и оставьте его работающим:

```powershell
npm run api:dev
```

Во втором терминале запустите интерфейс:

```powershell
npm run dev -- --host 127.0.0.1 --port 4173
```

Откройте `http://127.0.0.1:4173/`. API нужен для БКРС, своих карточек и данных
порядка черт. Docker работает в фоне: отдельный постоянно открытый терминал
ему не нужен. API и сайт остановятся по `Ctrl+C` в соответствующих терминалах.

На текущем компьютере БКРС уже импортирован. На новом компьютере пустая база
сама не скачает словарь: нужен импорт предоставленной выгрузки. Он также
используется при обновлении данных:

```powershell
npm run dictionary:import -- "C:\Users\Legion\Downloads\html_dabkrs_bruks\dabkrs_dabruks.html"
```

## Что происходит в папках

- `src/App.jsx` — вход в приложение.
- `src/features/study/StudyHome.jsx` — первая страница модуля «Учёба».
- `src/features/writing/` — прописи внутри каждого курса HSK: обводка по
  трафарету, повторение серии по памяти и последовательное написание слов.
- `src/data/studyDemo.js` — данные карточек уровней на главной странице.
- `src/data/hsk1Vocabulary.js` … `hsk6Vocabulary.js` — локальные каталоги
  слов для карточек HSK 1–6. Они подгружаются отдельно при открытии уровня.
- `src/data/hskCatalogs.js` — понятный список, который связывает страницу
  курса с нужным каталогом.
- `api/server.mjs` — API БКРС, локальных данных порядка черт и личных карточек.
- `api/personalCards.mjs` — защищённые ключом коллекции операции со своими словами.
- `api/personalFolders.mjs` — тематические папки, запись на курс и статистика.
- `src/features/study/StudySession.jsx` — перевод, ввод иероглифов и прописи.
- `src/features/study/ankiScheduler.js` — вычисление сроков повторения.
- `src/features/personal/` — создание/изменение карточек, практика, статистика.
- `infra/postgres/init/03-dictionary-schema.sql` — таблицы и индексы для
  многомиллионного словаря.
- `scripts/importBkrsDictionary.mjs` — безопасный импорт переданной HTML-выгрузки
  БКРС: он читает только статические записи, не запускает JavaScript из файла.
- `scripts/extractRussianHskPdfCatalogs.py` и
  `scripts/buildHsk2To6Catalogs.mjs` — извлечение слов, пиньиня и русских
  значений HSK 2–6 из предоставленных PDF и создание карточек сайта;
  инструкция и важная проверка прав описаны в `docs/08-hsk2-hsk6-catalogs.md`.
- `src/App.css` и `src/index.css` — внешний вид страницы.
- `src/responsive.css` — общие адаптивные правила и переносы текста.
- `docs/` — продуктовые заметки и порядок разработки.

## Первый самостоятельный шаг

В `src/features/study/StudyHome.jsx` найдите заголовок «Путь в тысячу ли начинается
с первого шага.» и попробуйте изменить текст. Сохраните файл (`Ctrl + S`)
и посмотрите, как браузер обновится сам.

Далее посмотрите `HskCourseHub.jsx` и `CourseSettingsForm.jsx`: первый показывает
разделы курса, второй собирает настройки перед запуском упражнения.

## Проверить изменения

```powershell
npm run lint
npm test
npm run build
```

Для проверки сохранения и разграничения доступа с настоящей локальной БД:

```powershell
$env:PERSONAL_CARDS_DB_TESTS = '1'
npm test
Remove-Item Env:PERSONAL_CARDS_DB_TESTS
```

Тест удаляет только созданные им временные коллекции. Обычный `npm test`
пропускает проверку БД, если переменная не задана.
